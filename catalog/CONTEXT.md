# Catalog(蔵書)

書誌と蔵書(個体)のマスタ管理。単純な登録・参照・更新のため Django 標準の CRUD 構成で実装する。

## Language

**書誌 (Title)**:
タイトル・著者・ISBN などの書籍情報。物理的な冊とは区別される。予約の対象になる単位。
_Avoid_: 本、書籍(個体と紛らわしい)

**蔵書 (Copy)**:
図書館が所蔵する物理的な 1 冊。1 つの書誌に複数の蔵書が属しうる。貸出の対象になる単位。
_Avoid_: 在庫、アイテム

**除籍 (Withdrawal)**:
蔵書を所蔵から外すこと。除籍された蔵書は貸出できない。
_Avoid_: 削除、廃棄
