# Customers(会員)

モバイルオーダーを使うお客様(会員)のマスタ管理。単純な登録・参照・更新のため Django 標準の CRUD 構成で実装する(画面は Django admin)。

## Language

**会員 (Customer)**:
モバイルオーダーに登録したお客様。注文の主体。
_Avoid_: ユーザー(認証用の `User` と区別する)、顧客

**会員ステータス (Customer Status)**:
会員の利用可否状態。「有効」または「利用停止」。利用停止中の会員は注文できない。利用停止は管理サイトから手動で行う。

**会員ランク (Customer Rank)**:
会員の格付け。「一般会員」「シルバー会員」「ゴールド会員」の 3 段階。ランクに応じて Ordering の割引率が変わる(`ordering/CONTEXT.md` の「割引率」参照)。ランクの昇降格ルール自体は現状扱わない。
_Avoid_: グレード、階級

**ポイント (Points)**:
受取が済んだ注文の支払額(割引後の合計)100 円につき 1 ポイント(端数切り捨て)。Ordering の `OrderPickedUp` を受けて加算する。ポイントの利用(支払いへの充当)は現状扱わない。
