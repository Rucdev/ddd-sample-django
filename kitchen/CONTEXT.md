# Kitchen(キッチン)

注文を受けて「何を作るか」と「調理の進み具合」を扱う。Ordering とは同じ注文を別の関心(金額・お客様ではなく、作業)から見るコンテキストで、ステータス遷移のルールを持つため DDD ベースで実装する。

## Language

**調理チケット (Ticket)**:
キッチンが作る作業指示。集約ルート。**注文明細 1 行(商品 × 数量)につき 1 枚**。Ordering の `OrderPlaced` を受けて、明細の数だけ作られる。キッチンは商品ごと(ドリンク・フードなど持ち場ごと)に作るので、同じ注文のチケットでもそれぞれ独立に進み、足並みはそろえない。注文としての「全部できたか」は Ordering が判断する。
_Avoid_: 注文(Ordering の「注文」と混同しない)、オーダー

**明細番号 (Line No)**:
チケットが注文の何行目の明細か(1 始まり)。Ordering から受け取り、`CookingStarted` / `CookingCompleted` に載せて「どの明細が進んだか」を Ordering に伝えるのに使う。画面のカードでは「2/3」(3 品中 2 品目)のように出す。

**チケット明細 (Ticket Item)**:
チケットに載る「何を何個作るか」。チケット 1 枚に 1 つ。商品名と数量だけを持ち、価格は持たない。
_Avoid_: 注文明細

**チケットステータス (Ticket Status)**:

| ステータス | 意味 |
| --- | --- |
| 調理待ち (QUEUED) | まだ作り始めていない |
| 調理中 (COOKING) | 作っている。`CookingStarted` を発行する |
| 調理済 (DONE) | できあがった。`CookingCompleted` を発行する |
| 取消 (CANCELLED) | 注文がキャンセルされた(同じ注文のチケットはまとめて取り消す。調理待ちのときだけ) |

**調理開始 / 調理完了 (Start Cooking / Complete Cooking)**:
キッチン担当者がチケットを進める操作。調理開始は調理待ちのとき、調理完了は調理中のときだけできる。
