# Kitchen(キッチン)

注文を受けて「何を作るか」と「調理の進み具合」を扱う。Ordering とは同じ注文を別の関心(金額・お客様ではなく、作業)から見るコンテキストで、ステータス遷移のルールを持つため DDD ベースで実装する。

## Language

**調理チケット (Ticket)**:
1 件の注文に対してキッチンが作る作業指示。集約ルート。注文 1 件につき 1 枚。Ordering の `OrderPlaced` を受けて作られる。
_Avoid_: 注文(Ordering の「注文」と混同しない)、オーダー

**チケット明細 (Ticket Item)**:
チケットに載る「何を何個作るか」。商品名と数量だけを持ち、価格は持たない。
_Avoid_: 注文明細

**チケットステータス (Ticket Status)**:

| ステータス | 意味 |
| --- | --- |
| 調理待ち (QUEUED) | まだ作り始めていない |
| 調理中 (COOKING) | 作っている。`CookingStarted` を発行する |
| 調理済 (DONE) | できあがった。`CookingCompleted` を発行する |
| 取消 (CANCELLED) | 注文がキャンセルされた(調理待ちのときだけ) |

**調理開始 / 調理完了 (Start Cooking / Complete Cooking)**:
キッチン担当者がチケットを進める操作。調理開始は調理待ちのとき、調理完了は調理中のときだけできる。
