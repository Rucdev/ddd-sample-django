# Members(会員)

図書館の利用者である会員のマスタ管理。単純な登録・参照・更新のため Django 標準の CRUD 構成で実装する。

## Language

**会員 (Member)**:
図書館に登録された利用者。貸出・予約の主体。
_Avoid_: ユーザー、利用者、顧客

**会員ステータス (Member Status)**:
会員の利用可否状態。「有効」または「停止」。停止中の会員は新規の貸出・予約ができない。

**貸出停止 (Suspension)**:
延滞発生(`LoanOverdue`)を受けて会員ステータスを「停止」にすること。延滞中の貸出がすべて返却されると解除される。
_Avoid_: 凍結、ブロック

**会員ランク (Member Rank)**:
会員の格付け。「一般会員」「シルバー会員」「ゴールド会員」の 3 段階。ランクに応じて Lending の貸出条件(貸出上限冊数・貸出期間)が変わる(`lending/CONTEXT.md` の「貸出条件」参照)。ランクの昇降格ルール自体は現状扱わない。
_Avoid_: グレード、階級
