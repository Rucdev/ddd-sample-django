# Menu(メニュー)

カフェで売っている商品のマスタ管理。単純な登録・参照・更新のため Django 標準の CRUD 構成で実装する(画面は Django admin)。

## Language

**カテゴリ (Category)**:
商品の分類(ドリンク、フード など)。メニューの並び順を決める。

**商品 (Menu Item)**:
カフェで売っている 1 品。名前と税込価格(円)を持つ。注文の対象になる単位。
_Avoid_: メニュー(一覧全体を指すのと紛らわしい)、アイテム

**品切れ (Sold Out)**:
スタッフが手で商品を一時的に注文できなくしている状態。品切れの商品は注文画面に出ず、注文もできない。
