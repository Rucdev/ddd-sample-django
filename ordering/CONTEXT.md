# Ordering(注文)

お客様の注文の受付・キャンセル・受取(提供)と、金額計算(割引を含む)、店内の席ごとの会計を扱うコアドメイン。ステータス遷移と金額のルールが集中するため DDD ベースで実装する。

注文には**持ち帰り**(会員のモバイルオーダー。カウンターで受け取る)と**店内**(席から頼み、店員が席まで運ぶ)の 2 種類がある。

## Language

**注文 (Order)**:
お客様が 1 回にまとめて頼んだ商品と、その受け渡しの進み具合。集約ルート。持ち帰りの注文は会員が、店内の注文は席の会計が持ち主になる(どちらか一方だけ)。
_Avoid_: オーダー、伝票、カート

**注文の種類 (Order Type)**:

| 種類 | 誰が頼むか | 受け渡し | 支払い |
| --- | --- | --- | --- |
| 持ち帰り (TAKEOUT) | 会員(会員登録が必要) | お客様がカウンターで受け取る(受取) | 注文ごと。会員ランクの割引とポイントあり |
| 店内 (DINE_IN) | 席に座っているお客様(会員登録は不要) | 店員が席まで運ぶ(提供) | 席の会計でまとめて。割引・ポイントなし |

**注文明細 (Order Line)**:
注文の中の 1 行。「どの商品を、いくらで、何個」。商品名と単価は注文時点の値をスナップショットとして持ち、あとでメニューの価格が変わっても注文の金額は変わらない。数量は 1 明細あたり 1〜10 個。
_Avoid_: アイテム、行

**明細の調理状況 (Line Cooking Status)**:
注文明細 1 行ごとの、キッチンでの進み具合。待ち (WAITING) → 調理中 (COOKING) → できあがり (DONE)。キッチンは商品ごとに作るので、Kitchen の `CookingStarted` / `CookingCompleted` は明細ごとに届き(明細番号つき)、明細ごとに進む。注文ステータスの「調理中」「受取可」はここから決まる。

**注文ステータス (Order Status)**:

| ステータス | 意味 | 何で遷移するか |
| --- | --- | --- |
| 受付済 (PLACED) | 注文を受け付けた。まだ作り始めていない | 注文 |
| 調理中 (PREPARING) | キッチンがどれか 1 品でも作り始めた | 最初の明細の `CookingStarted` |
| 受取可 / 提供待ち (READY) | 全部の明細ができあがった。持ち帰りなら受け取り、店内なら席への提供を待っている | 最後の明細の `CookingCompleted` |
| 受取済 (PICKED_UP) | お客様が受け取った(持ち帰りのみ) | 受取 |
| 提供済 (SERVED) | 店員が席まで運んだ(店内のみ) | 提供完了 |
| キャンセル (CANCELLED) | 取り消された | キャンセル(受付済のときだけ) |

**進行中の注文 (In-progress Order)**:
受付済・調理中・受取可の注文。1 人の会員が同時に持てる進行中の注文(持ち帰り)は 3 件まで。店内の注文には上限はない。

**キャンセル (Cancellation)**:
注文を取り消すこと。調理が始まる前(受付済)だけできる。1 品でも作り始めたら、注文ごと取り消せない(一部の明細だけのキャンセルはしない)。席からは、その席でいま開いている会計の注文だけを取り消せる。
_Avoid_: 取消(Kitchen の「チケット取消」と区別する)

**受取 (Pick-up)**:
受取可になった持ち帰りの注文を、お客様がカウンターで受け取ること。`OrderPickedUp` イベントを発行し、Customers がポイントを付与する。
_Avoid_: 提供、引き渡し

**提供 / 提供完了 (Serve)**:
提供待ちになった店内の注文を、店員が席まで運ぶこと。運んだら店員がホール画面で「提供完了」を押し、注文は提供済になる。支払いは会計でまとめて行うので、ここではポイントも支払いも起きない。
_Avoid_: 受取(持ち帰りの受け渡しと区別する)、配膳

**会計 (Bill)**:
席の利用 1 回分の店内注文をまとめて支払う単位。集約ルート。席の利用が始まる(Seating の `SeatOccupied`)と開き、その間に席から頼んだ注文はすべてこの会計に紐づき、明細として残る。席の利用が終わる(Seating の `SeatVacated` = 退席)と支払済になる。同じ席が次に使われるときは新しい会計が開く。1 つの席に開いている会計は高々 1 つ。
_Avoid_: 伝票、レシート、テーブルチェック

**会計のステータス (Bill Status)**:

| ステータス | 意味 | 何で遷移するか |
| --- | --- | --- |
| 利用中 (OPEN) | 席が使われていて、注文を足せる | 席の利用開始(案内・着席) |
| 支払済 (PAID) | 支払いが済んだ。もう注文は足せない | 席の利用終了(退席) |

**会計の金額 (Amount Due)**:
会計に紐づく注文の合計の和。キャンセルした注文は含めない。

**小計 / 割引額 / 合計 (Subtotal / Discount / Total)**:
小計 = 明細の (単価 × 数量) の合計。割引額 = 小計 × 割引率(1 円未満切り捨て)。合計 = 小計 − 割引額。

**割引率 (Discount Rate)**:
会員ランクに応じて決まる、小計に対する割引の割合。持ち帰りの注文だけにかかる(店内の注文は会員と結びつかないので割引なし)。

| 会員ランク | 割引率 |
| --- | --- |
| 一般会員 | 0% |
| シルバー会員 | 5% |
| ゴールド会員 | 10% |
