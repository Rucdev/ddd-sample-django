# Ordering(注文)

お客様の注文の受付・キャンセル・受取と、金額計算(割引を含む)を扱うコアドメイン。ステータス遷移と金額のルールが集中するため DDD ベースで実装する。

## Language

**注文 (Order)**:
お客様が 1 回の会計でまとめて頼んだ商品と、その受け渡しの進み具合。集約ルート。
_Avoid_: オーダー、伝票、カート

**注文明細 (Order Line)**:
注文の中の 1 行。「どの商品を、いくらで、何個」。商品名と単価は注文時点の値をスナップショットとして持ち、あとでメニューの価格が変わっても注文の金額は変わらない。数量は 1 明細あたり 1〜10 個。
_Avoid_: アイテム、行

**注文ステータス (Order Status)**:

| ステータス | 意味 | 何で遷移するか |
| --- | --- | --- |
| 受付済 (PLACED) | 注文を受け付けた。まだ作り始めていない | 注文 |
| 調理中 (PREPARING) | キッチンが作り始めた | Kitchen の `CookingStarted` |
| 受取可 (READY) | できあがり、受け取りを待っている | Kitchen の `CookingCompleted` |
| 受取済 (PICKED_UP) | お客様が受け取った | 受取 |
| キャンセル (CANCELLED) | 取り消された | キャンセル(受付済のときだけ) |

**在庫不足 (Out of Stock)**:
商品を作るキットの注文可能数が、注文の数量に足りないこと。注文全体が受け付けられない。在庫の判定は Inventory が行い、注文を受け付けた時点でキットを消費し、キャンセルで戻す。キットを登録していない商品には在庫の制限はない。

**進行中の注文 (In-progress Order)**:
受付済・調理中・受取可の注文。1 人のお客様が同時に持てる進行中の注文は 3 件まで。

**キャンセル (Cancellation)**:
注文を取り消すこと。調理が始まる前(受付済)だけできる。作り始めた商品は取り消せない。
_Avoid_: 取消(Kitchen の「チケット取消」と区別する)

**受取 (Pick-up)**:
受取可の注文をお客様が受け取ること。`OrderPickedUp` イベントを発行し、Customers がポイントを付与する。
_Avoid_: 提供、引き渡し

**小計 / 割引額 / 合計 (Subtotal / Discount / Total)**:
小計 = 明細の (単価 × 数量) の合計。割引額 = 小計 × 割引率(1 円未満切り捨て)。合計 = 小計 − 割引額。

**割引率 (Discount Rate)**:
会員ランクに応じて決まる、小計に対する割引の割合。

| 会員ランク | 割引率 |
| --- | --- |
| 一般会員 | 0% |
| シルバー会員 | 5% |
| ゴールド会員 | 10% |
