# Seating(座席)

店内の座席の構成と、いまどの席が空いているかを扱う。席の構成はファイル(座席構成ファイル)で管理し、席ごとのステータス(空き・予約中・使用中)は DB で管理する。ステータスの遷移にルールがあるので DDD ベースで実装する。注文・調理とはつながっていない(注文はどの席に座っているかを知らない)。

## Language

**座席構成ファイル (Seat Layout File)**:
エリアと席の一覧を書いた YAML ファイル(`seating/seat_layout.yaml`。場所は `settings.SEAT_LAYOUT_FILE`)。席の「形」— どのエリアにあるか、何人座れるか、見取り図のどこに描くか — の正本はこのファイルで、画面や admin からは変えない。`manage.py apply_seat_layout` で DB に反映する。
_Avoid_: 座席マスタ(admin で編集するものと誤解させる)

**座席構成 (Seat Layout)**:
座席構成ファイルを読んだもの。席コード・エリアコードが重複しない、席が既知のエリアに属する、同じエリアで席の位置が重ならない、を満たす。

**反映 (Apply)**:
座席構成を DB に写す操作。席コードで突き合わせ、新しい席は「空き」で置き、残る席はエリア・定員・位置だけを書き換えて**ステータスは保つ**。ファイルから消えた席は撤去する。何度流しても同じ結果になる。

**エリア (Area)**:
カウンター・テーブル席・テラスなど、席のまとまり。画面ではエリアごとに見取り図を描く。並び順はファイルに書いた順。

**席 (Seat)**:
お客様が座る単位。集約ルート。席コード(`T1` など。店員が口にする呼び名)で識別し、定員(何人座れるか)と見取り図上の位置(行・列)を持つ。コードを変えると別の席になる(撤去して新設)。
_Avoid_: テーブル(カウンター席も含むので)

**席のステータス (Seat Status)**:

| ステータス | 意味 |
| --- | --- |
| 空き (AVAILABLE) | 誰も座っておらず、押さえられてもいない |
| 予約中 (RESERVED) | 来店予定のお客様のために押さえている |
| 使用中 (OCCUPIED) | お客様が座っている |

**予約 / 予約取消 (Reserve / Cancel Reservation)**:
空きの席を予約中にする / 予約中の席を空きに戻す。予約者の名前や時刻はまだ扱わない。

**案内 / 着席 (Occupy)**:
席を使用中にする。予約なしのお客様を空き席に通すのが「案内」、予約していたお客様が座るのが「着席」で、どちらも同じ操作。

**退席 (Vacate)**:
使用中の席を空きに戻す。片付けの状態は持たず、退席したらすぐ次のお客様を通せる扱い。

**撤去 (Remove)**:
座席構成ファイルから消えた席を DB から外すこと。**空きの席しか撤去できない**。予約中・使用中の席が 1 つでも撤去対象にあると、反映ごと断る(お客様を置き去りにしないため)。

**使用率 (Occupancy Rate)**:
使用中の席数 ÷ 全席数。人数ではなく席数で数える。
